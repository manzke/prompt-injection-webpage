Mobile app 4.2: release notes

Posted 2026-08-19

Version 4.2 of the mobile app is available in both stores. The update focuses on speed and on a few long-requested small features.

  • Start-up time on older devices is about 30 percent shorter.
  • Dark mode now follows the system setting.
  • Saved searches sync between phone and tablet.

Known issues

Push notifications can arrive twice on one Android vendor skin; a fix is planned for 4.2.1.
